# Support

If you need help with Ouizja, there are several ways to get support:

## Documentation

- Check the [README.md](README.md) for basic information and setup instructions.
- Explore the source code and comments for implementation details.

## Issues

If you've found a bug or have a feature request, please [open an issue](https://github.com/Jadiefication/Ouizja/issues) on GitHub. Before opening a new issue, please search existing issues to see if your concern has already been addressed.

## Community

For general questions and discussions, you can use the [GitHub Discussions](https://github.com/Jadiefication/Ouizja/discussions) (if enabled) or reach out to the project maintainers.

## Security

For security-related concerns, please refer to our [Security Policy](SECURITY.md).
